# 🧠 مهارة «كلود» — التعاون المعماري الثنائي (Dual-Brain Architecture)

هذه المهارة تحدد بروتوكول التعاون بين:
1. **Claude (المخ والمستشار المعماري):** يضع التصورات المعمارية النظيفة، يراجع الأكواد، يقترح أفضل الـ Patterns، ويدقق منطق الحسابات والـ UX.
2. **Antigravity (المخ المنفذ والعضلات):** يربط الأكواد بالبيئة المحلية (Windows / Electron / Node / SQLite)، يكتب الملفات، يثبت الحزم، يفحص الأخطاء لحظياً، ويشغل المشروع ويختبره على أرض الواقع.

---

## 🔄 بروتوكول دورة العمل (The Workflow Loop)

```
[صياغة متطلب التطوير] ──▶ [Antigravity: توليد برومبت استشاري دقيق] ──▶ [المستخدم: نسخ إلى Claude]
                                                                                │
                                                                                ▼
[Antigravity: فحص، تشغيل، واختبار] ◀── [المستخدم: لصق كود/رأي Claude] ◀── [Claude: المعمارية والكود]
```

---

## 🛠️ المهام الرئيسية للمهارة

### 1. تجهيز "حزمة استشارة كلود" (Generate Claude Consultation Prompt)
عند بدء أي شاشة أو ميزة جديدة، يقوم Antigravity بتجهيز نص منظم وجاهز للنسخ بنقرة واحدة يشمل:
* **سياق النظام:** (نظام الصواف للأقمشة، أوفلاين، صعيد مصر).
* **المهمة المحددة:** (مثال: محرك حساب أمتار التوب والكسور، أو مكون شاشة الكاشير السريعة).
* **القيود والمعايير:** (TypeScript صارم، Tailwind CSS فاخر، أداء فائق، معالجة الأخطاء).
* **الأسئلة المحورية:** التي نريد من كلود الإجابة عنها وتقديم كودها.

### 2. استقبال وتدقيق نتاج كلود (Ingest & Execute Claude Code)
عندما ينسخ المستخدم رد أو كود كلود هنا:
* **التدقيق والتكامل:** التأكد من توافق الكود مع بقية ملفات المشروع وقاعدة البيانات.
* **التنفيذ الفعلي:** إنشاء الملفات وكتابة الكود في مسار العمل فوراً.
* **حل المشاكل الصامتة:** سد أي نواقص (Imports مفقودة، Types غير معرفة، حزم تحتاج تثبيت).
* **الاختبار والتأكيد:** تشغيل الكود وفحصه والتأكد من خلوه من أي Syntax أو Runtime Errors.

### 3. توليد تقرير الإنجاز / التغذية الراجعة لكلود
* صياغة ملخص سريع ومرتب لما تم تنفيذه، لتقوم بنسخه لكلود إن أردت استشارته في الخطوة التالية.

## 📋 قواعد الجودة والتكامل
* **لا أخطاء في الكود:** كل كود يتم وضعه يُفحص فورياً.
* **الحفاظ على هوية الصواف:** (أخضر زيتي وذهبي، واجهة عربية RTL، دعم الكسور، مقاومة انقطاع الكهرباء).
* **استغلال تعدد حسابات كلود:** توزيع المهام المعقدة للحصول على أعمق نتيجة ممكنة من كل جلسة مجانية.
* **الأتمتة السريعة للجلسات:** عند انتهاء رسائل الجلسة الحالية، يمكن استدعاء مهارة [`claude-session`](../claude-session/SKILL.md) لتوليد إيميل مؤقت وتجهيز رابط دخول الحساب الجديد وفتحه في ثوانٍ حتى خطوة التحقق.
