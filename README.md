# منظومة الصواف للأقمشة والمنسوجات — Al-Sawaf Fabrics POS & ERP

> **منظومة بيع ذكية، إدارة مخازن الأتواب، وسجلات الحسابات والآجل مصممة خصيصاً لتجارة وتجزئة الأقمشة في صعيد مصر.**

---

## 🌟 نظرة عامة (Overview)

منظومة **الصواف للأقمشة** هي منصة بيع متكاملة (POS / ERP) تعمل بمبدأ **Offline-First** الصارم لضمان عدم توقف العمل عند انقطاع الإنترنت أو التيار الكهربائي. تم تصميم النظام وفقاً للواقع التجاري الفعلي لمحلات ووكالات الأقمشة في صعيد مصر ومراكز المحلة الكبرى، حيث يعالج التحديات الفريدة للقطاع:

- **إدارة الأتواب والكسور (Bolt Tracking & Fractional Cuts):** لا يتم بيع الأقمشة كوحدات عددية، بل كأمتار وكسور دقيقة من أتواب محددة تتبع أرقام الصبغات (`Dye-lot`).
- **خوارزمية تصفية الفضلات (Bolt-Buster Algorithm):** حماية أصحاب المحال من بقاء أطراف أتواب ميتة لا تكفي ثوباً ولا جلابية (أقل من 2.5 متر)، وحث الكاشير على بيعها بخصم تصفية فوري.
- **حسابات مالية صارمة خالية من الكسور العائمة (Integer Math / Qirsh & Cm):** منع تآكل الأرباح الناتج عن التقريب العشري، باستخدام `BigInt` وخوارزمية أكبر البواقي (Largest Remainder Method).
- **الدفاتر القبلية والائتمان الموسمي (Tribal Credit Ledger):** نظام تسجيل الآجل ومتابعة مواسم السداد الحصادية (موسم كسر القصب في الشتاء، وموسم توريد القمح في الصيف).
- **عمولات الترزية والمفصلات (Tailor Commission Management):** قيد آلي لعمولة الترزي بالـ (متر/جنيه) مع إمكانية المقاصة العينية بالأقمشة أو الصرف النقدي.
- **إدارة جهاز العروسة (Bridal Dossier):** تقسيم الغرف، أطقم السرير، الستائر، وإصدار إذن صرف الورش والمفصلات (Fabric Packing Slip).

## 🛠️ البنية التقنية (Architecture & Tech Stack)

- **Frontend / UI:** React 18 + TypeScript + Vite.
- **Styling:** Custom Luxury Boutique Design System (`Royal Obsidian & Gold`, RTL Native, Dark & Light modes).
- **Sound Engine:** Synthesized Web Audio API (صوت مقص الأقمشة، فتح الدرج، وختم الآجل القبلي).
- **Backend / Storage (Desktop):** Node.js 26 Native `node:sqlite` (`DatabaseSync`) مع تفعيل `WAL Mode` و `Append-Only Financial Ledgers` مع تريجرات تمنع الحذف أو التعديل لحماية الدفاتر المحاسبية.
- **Printing:** قوالب فواتير حرارية قياسية `80mm Thermal Receipt` مع باركود Code39 وروابط WhatsApp مباشرة للعملاء.

## 🚀 التشغيل السريع (Quick Start)

### المتطلبات:
- Node.js (الإصدار 20+ أو Node 26 المدمج به SQLite).
- npm أو pnpm.

### خطوات التثبيت:
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# فحص الأنواع (Typecheck)
npm run typecheck

# تشغيل الاختبارات الآلية
npm test
```

### التشغيل كبرنامج سطح مكتب فوري (Windows):
- انقر مرتين على ملف: `تشغيل_منظومة_الصواف.bat`

## ⌨️ مفاتيح الاختصار الميدانية (Cashier Hotkeys)

| الزر | الوظيفة |
|---|---|
| **F1** | بحث فوري بالاسم أو كود التوب |
| **F2** | التركيز على اختيار العميل |
| **F3** | حاسبة مقاسات الصعيد والجلابيب |
| **F4** | فتح ملف جهاز العروسة (Bridal Dossier) |
| **F8** | سجل فواتير اليوم والوردية وإعادة الطباعة |
| **F9** | إدارة النثريات وتقفيل الوردية (Petty Cash) |
| **F10** | اعتماد البيع بالآجل (شكك قبلي) |
| **F12 / Ctrl+Enter** | اعتماد البيع كاش نقدي فوري |
| **Esc** | إفراغ السلة أو إغلاق النوافذ المنبثقة |
